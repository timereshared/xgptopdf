# Examples of xgptopdf output

These PDFs were prodyced by xgptopdf using original XGP spool files from
saildart.org

* [AD.XGP[B,LES]](AD.XGP[B,LES].pdf) - San Jose Bicycle Club flyer (Les Earnest, 1978)
* [ENERGY.XGP[CUR,JMC]](ENERGY.XGP[CUR,JMC].pdf) - Statement of ad hoc committee on Project Independence (John McCarthy, 1974_
* [ERRATA.XGP[ART,DEK]](ERRATA.XGP[ART,DEK].pdf) - The Art of Computer Programming errata (Donald Knuth, 1979)
* [FAIL.XGP[AIM,DOC]](FAIL.XGP[AIM,DOC].pdf) - Manual for the FAIL assembler (Reg Gorin and F Wright, 1975_
* [HOMEW1.XGP[206,LSP]](HOMEW1.XGP[206,LSP].pdf) - Homework from Lisp class CS206 (Unknown, 1979)
* [LRNSAM.XGP[MUS,DOC]](LRNSAM.XGP[MUS,DOC].pdf) - System Concepts Digital Synthesizer operation manual and tutorial (Gareth Loy, 1979)
* [MONCOM.XGP[CSP,DOC]](MONCOM.XGP[CSP,DOC].pdf) - WAITS Monitor command manual (Brian Harvey, 1978)
* [POX.XGP[UP,DOC]1](POX.XGP[UP,DOC]1.pdf) - POX document language manual (Robert Elton Mass. 1975)
* [SUAI.XGP[1,ALS]](SUAI.XGP[1,ALS].pdf) - Short WAITS, an introduction to the WAITS system (Arthur Samuel, 1980)
* [YUMMY.XGP[P,DOC]1](YUMMY.XGP[P,DOC]1.pdf) - International Yum Yum restaurant guide (Various, 1978)

There are several hundred XGP files stored in the
[saildart.org](https://www.saildart.org) archive - and potentially many
more that can be recreated from their PUB or POX originals - so go and
explore, and let me know if you find anything interesting.
