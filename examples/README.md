# Examples of xgptopdf output

These PDFs were produced by xgptopdf using original XGP spool files from
saildart.org. As the Github PDF preview does not always work I recommend
downloading these via the links below and viewing on your computer.

* <a href="AD.XGP[B,LES].pdf" download>AD.XGP[B,LES]</a> - San Jose Bicycle Club flyer (Les Earnest, 1978)
* <a href="ENERGY.XGP[CUR,JMC].pdf" download>ENERGY.XGP[CUR,JMC]</a> - Statement of ad hoc committee on Project Independence (John McCarthy, 1974)
* <a href="ERRATA.XGP[ART,DEK].pdf" download>ERRATA.XGP[ART,DEK]</a> - The Art of Computer Programming errata (Donald Knuth, 1979)
* <a href="FAIL.XGP[AIM,DOC].pdf" download>FAIL.XGP[AIM,DOC]</a> - Manual for the FAIL assembler (Reg Gorin and F Wright, 1975)
* <a href="HOMEW1.XGP[206,LSP].pdf" download>HOMEW1.XGP[206,LSP]</a> - Homework from Lisp class CS206 (Unknown, 1979)
* <a href="LRNSAM.XGP[MUS,DOC].pdf" download>LRNSAM.XGP[MUS,DOC]</a> - System Concepts Digital Synthesizer operation manual and tutorial (Gareth Loy, 1979)
* <a href="MONCOM.XGP[CSP,DOC].pdf" download>MONCOM.XGP[CSP,DOC]</a> - WAITS Monitor command manual (Brian Harvey, 1978)
* <a href="POX.XGP[UP,DOC]1.pdf" download>POX.XGP[UP,DOC]1</a> - POX document language manual (Robert Elton Mass. 1975)
* <a href="SUAI.XGP[1,ALS].pdf" download>SUAI.XGP[1,ALS]</a> - Short WAITS, an introduction to the WAITS system (Arthur Samuel, 1980)
* <a href="YUMMY.XGP[P,DOC]1.pdf" download>YUMMY.XGP[P,DOC]1</a> - International Yum Yum restaurant guide (Various, 1978)

There are several hundred XGP files stored in the
[saildart.org](https://www.saildart.org) archive - and potentially many
more that can be recreated from their PUB or POX originals - so go and
explore, and let me know if you find anything interesting.
